# Пътна помощ Велико Търново

Mobile-first static website for a 24/7 towing and roadside-assistance service in Veliko Tarnovo, Bulgaria.

## Structure

- `index.html` — semantic page content and SEO metadata
- `styles.css` — mobile-first responsive design
- `script.js` — privacy-conscious location sharing
- `assets/` — locally hosted photographs and favicon

The location feature runs entirely in the visitor's browser. It asks for permission, creates a Google Maps link locally, and lets the visitor choose how to share it. The website does not receive or store coordinates.

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the default branch and **/(root)**, then save.

Expected URL: https://flamingb1rd.github.io/patna-pomosht-vt/
